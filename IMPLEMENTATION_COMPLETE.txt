## 🎓 DECISIONES TOMADAS (JUSTIFICADAS)

### 1. ¿Por qué Tailwind CSS?
- Bundle size mínimo (15KB vs 180KB)
- Customización ilimitada
- Desarrollo más rápido
- Ideal para Angular moderno

### 2. ¿Por qué componentes standalone?
- Angular 21+ estándar
- Menos boilerplate
- Más modular y testeable

### 3. ¿Por qué Reactive Forms?
- Control granular
- Validación avanzada
- Type-safe
- Mejor testing

### 4. ¿Por qué HttpInterceptor?
- Centraliza lógica de token
- No repetir código
- Manejo global de errores

## 📞 NOTAS PARA EL EQUIPO BACKEND

### Endpoints requeridos:

**1. POST /api/cliente/login**
```json
{
  "user": "username",
  "password": "password"
}
→ Retornar: { token, user, authorities }
```

**2. POST /api/cliente/guardar**
```json
{
  "identificacion": "...",
  "nombres": "...",
  "apellidos": "...",
  "email": "...",
  "estado": 1,
  "username": "...",
  "password": "...",
  "roles": ["ROLE_USER"]
}
```

### Notas importantes:
- ✅ Ambos endpoints son públicos (sin token)
- ✅ El frontend inyecta automáticamente token en otras peticiones
- ✅ Header esperado: `Authorization: Bearer {token}`
- ✅ Formato de error esperado: `{ message: "error..." }`
